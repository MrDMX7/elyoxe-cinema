# elyoxe.com/cinema Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A live, indexable Arabic-first UAE cinema guide at elyoxe.com/cinema with real per-seat prices and price-after-card-discount, refreshed 3×/day.

**Architecture:** Seven chain readers → `refresh.py` merges into `data/latest.json` (+ TMDB/OMDb enrichment, hand-kept verdicts and discounts) → `build.py` renders static pages with the /tools identity → `deploy.sh` syncs `cinema/` and `en/cinema/` into the tools bucket behind two new CloudFront behaviors.

**Tech Stack:** Python 3.13 stdlib + `requests` (+ `pyyaml`), vanilla JS, pytest. No framework.

**Spec:** `docs/superpowers/specs/2026-09-25-cinema-design.md`

## Global Constraints
- Western numerals 0-9 only, never ٠-٩, in every page and verdict.
- No invented numbers: a price with no source is shown as «السعر في الشباك», never estimated.
- Identity: `/tools/assets/base.css` + `cinema.css`; paper `#F4F2ED`, ink `#141A17`, saffron `#8F5400`; no radius, no shadow; numbers in IBM Plex Mono.
- Verdicts in light Emirati Arabic per `feedback_emirati_dialect` (شو not وش, مب, يستاهل…); read that memory file in full before writing any.
- Readers never log in, never hold seats beyond a price read, ≤1 request/second per chain.
- Paths inside strings use forward slashes (Windows).
- Deploy touches only `cinema/*` and `en/cinema/*` in the bucket.

## File map
- `readers/common.py` — HTTP session (UA, retry, 1 rps), `Show`/`Cinema` dict builders, `slug()`.
- `readers/{vox,star,cineroyal,novo,reel,roxy,cinemacity}.py` — `fetch(days:int=2) -> {"cinemas":[Cinema], "shows":[Show]}`.
- `fixtures/<chain>.json` — one real normalized response per chain (tests run offline on it).
- `normalize.py` — `merge(results:dict[str,dict], previous:dict|None) -> dict` (latest.json shape; stale-chain carry-over; cross-chain film merge).
- `enrich.py` — `enrich(data:dict, cache_path:str) -> dict` (TMDB + OMDb, cached in `data/films_cache.json`).
- `discounts.yaml` + `discounts.py` — `load() -> dict`, `apply(price:float, chain:str, hall:str, card:str) -> (float|None, str)`.
- `verdicts/<fid>.json` — hand/Claude-written.
- `refresh.py` — runs readers, merge, enrich, writes `data/latest.json`, exit 1 if every chain failed.
- `build.py` + `src/page.html` + `src/cinema.css` + `src/cinema.js` — static site into `out/`.
- `deploy.sh`, `wire_cloudfront.py` — publish.
- `.github/workflows/refresh.yml` (or Fold cron, chosen after Task 1).
- `tests/` — pytest per module.
