# «سينما» Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild «سينما» on cinema.elyoxe.com with the approved «هـ» design and all phase-1 features, keeping every current page and the Fold refresh working.

**Architecture:** Same pipeline (readers → refresh → latest.json → build.py static pages → S3/CloudFront, run on the Fold). New: a subdomain distribution, richer film/show/cinema data, a new template + CSS design system, and a client script that owns city/card/filters/nearest/ticket-sheet/prayer/PWA.

**Tech Stack:** Python 3.13 (build, data), vanilla JS (no framework), self-hosted fonts, AWS CLI (S3, CloudFront, ACM, Route53), pytest.

**Spec:** `docs/superpowers/specs/2026-09-26-phase1-design.md` (visual reference: canvas row «هـ»).

## Global Constraints
- Colors, fonts, brief rules exactly as the spec's Identity section; Western digits only; no invented numbers («السعر في الشباك» when unknown); «تقريباً» on every computed end time.
- Arabic at `/`, English at `/en/`, RTL derived with logical properties; works at 375 px with no horizontal scroll.
- Only confirmed-official discounts and cards appear.
- Budgets: HTML ≤ 150 KB/page, JS ≤ 45 KB gz, Lighthouse mobile ≥ 90 on home + a film page.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; this repo is pull-only in wsync — push explicitly; CI (`.github/workflows/test.yml`) must stay green.
- Never touch the tools bucket prefixes other than `cinema/` and `en/cinema/`; never deploy the studio site.
