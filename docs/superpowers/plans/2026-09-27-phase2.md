# «سينما» Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the phase-2 content and intelligence features on cinema.elyoxe.com without breaking the live hourly-ready pipeline.

**Architecture:** First make build.py extensible (a `pages/` package: each feature registers its pages, data slices, CSS and JS module), then build features in parallel, each in its own files, on branch `phase2`; merge to main per task after review so the live site gains features incrementally.

**Tech Stack:** Python 3.13, vanilla JS modules under src/js, pytest + node tests, existing readers/refresh/build/deploy.

**Spec:** `docs/superpowers/specs/2026-09-27-phase2-design.md`

## Global Constraints
- Phase-1 identity and rules (spec 2026-09-26) unchanged; Western digits; no invented numbers; «تقريباً» on estimates; only confirmed discounts; ar + /en/; HTML ≤ 150 KB/page; JS bundle ≤ 45 KB gz total (new modules lazy-loaded when large).
- Chain politeness: shared daily cache; occupancy sampling ≤ 1 req/s, ≤ 60 per chain per run, only shows starting within 3 h; never hold a seat, never log in.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; never commit to main directly; the Fold runs main.
